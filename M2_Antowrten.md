Aufgabe 2:
1)Datenbank-Tool in PhpStorm:
Ein nützliches Feature in PhpStorm ist das Datenbank-Tool. Damit können wir direkt in der IDE sehen, welche Tabellen es in unserer PostgreSQL-Datenbank gibt, welche Spalten sie haben und welche Daten gespeichert sind. Das war sehr hilfreich, weil wir so schnell prüfen konnten, ob unsere Migrationen und Seeder richtig funktioniert haben, zum Beispiel bei ab_user, ab_article und ab_articlecategory. Man kann dort auch direkt SQL-Abfragen ausführen. Das spart Zeit und hilft uns, Fehler in der Datenbank schneller zu finden.
2)Git-Integration in PhpStorm
Ein weiteres nützliches Feature in PhpStorm ist die Git-Integration. Damit können wir direkt sehen, welche Dateien geändert wurden, und Änderungen einfacher committen. Das ist besonders praktisch bei Teamarbeit, weil man den Überblick über den eigenen Code behält. So arbeitet man ordentlicher und vermeidet leichter Fehler.
3)Code-Vervollständigung in PhpStorm
Ein weiteres nützliches Feature in PhpStorm ist die Code-Vervollständigung. Beim Schreiben von Code zeigt die IDE passende Vorschläge für Befehle, Methoden oder Variablen an. Das ist besonders hilfreich, weil man schneller arbeiten und Tippfehler vermeiden kann. So wird der Code oft sauberer und leichter zu schreiben.

Aufgabe 4:
Wir vergleichen JavaScript mit C++.

6 Gemeinsamkeiten

1. Rechnen mit Zahlen
   Beide Sprachen können mit Zahlen rechnen.
   Beispiel: let x = 3 + 2; und int x = 3 + 2;

2.if-Abfragen
   Beide Sprachen können Bedingungen prüfen.
   Beispiel: if (x > 3) { ... }

3.Schleifen
   Beide haben Schleifen, zum Beispiel for.
   Beispiel: for (...) { ... }

4.Funktionen
   In beiden Sprachen kann man Funktionen schreiben.
   Beispiel: add(a, b)

5.Operatoren
   Beide benutzen Operatoren wie +, -, *, /.
   Beispiel: x + y

6.Arrays
   Beide können mehrere Werte in einem Array speichern.
   Beispiel: [1,2,3]

6 Unterschiede

1.Variablen
   In C++ schreibt man bei einer Variable den Datentyp dazu.
   In JavaScript benutzt man oft let.
   Beispiel: int x = 5; in C++ und let x = 5; in JavaScript.

2.Ausgabe
   In JavaScript nutzt man oft console.log().
   In C++ nutzt man cout.

3.Ausführung
   JavaScript läuft oft im Browser.
   C++ wird kompiliert und dann als Programm ausgeführt.

4.Objekte und Klassen
   JavaScript arbeitet viel mit Objekten.
   C++ arbeitet mehr mit Klassen.

5.Speicherverwaltung
   In JavaScript wird vieles automatisch verwaltet.
   In C++ muss man mehr selbst beachten.

6.Programmstart
   C++ startet meistens mit main().
   JavaScript braucht oft keine main()-Funktion.
